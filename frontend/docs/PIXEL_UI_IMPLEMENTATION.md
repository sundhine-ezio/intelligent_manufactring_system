# 像素风前端实施说明

## 目标

以 `前端页面设计/` 中的八张 1672×941 示意图作为桌面端默认画面，使用 Vue 3 和 Vue Router 提供可点击的导航与操作热区。进入数据操作区后，沿用原有 Vue 页面、SVG 地图和 ECharts 图表执行真实交互。窄屏继续使用响应式 Vue 页面。

## 页面映射

| 路由 | 对应示意图 | 保留的业务能力 |
| --- | --- | --- |
| `/` | 总览工作台 | 五个模块入口、业务流程、演示标识 |
| `/agv` | AGV 调度 | 地图、任务、车辆状态、路径与模拟运行 |
| `/vision` | 表面质量 / 物体定位 | 两个任务页签、样例、上传、结果展示 |
| `/monitor` | 设备状态监测 | 规划中占位，不展示虚构传感器数据 |
| `/orders` | 订单预测 | 真实历史销量与演示预测的区分 |
| `/energy` | 能源节约 | 参数输入、能耗计算及结构分析 |
| `/guide` | 使用说明 | 演示顺序和答辩边界说明 |

## 视觉与实现约束

- 使用暖色厂房插画、深紫面板、青色描边、浅绿色主要操作和方形像素边框。
- 中文正文使用清晰的系统字体，避免为了像素感牺牲可读性。
- 八张桌面默认画面直接引用项目内的设计 PNG，因此在原尺寸下保留全部插画、边框、文字和布局；路由导航、页签及主要操作按钮用透明可聚焦热区实现。
- 点击数据区或主要操作后，在设计图的厂房侧栏内展开真实 Vue 操作区。此时数据、地图和图表随用户操作变化，静态设计图中的示例数值不再作为运行结果。
- 顶栏窗景、侧栏盆栽货箱、模块卡片、监测设备和指南流水线使用项目内手绘 SVG；面板亮角、警戒线和分栏由 CSS 实现。
- AGV 工位增加可辨识的加工、检测、复检、充电等图形；工位坐标与任务交互仍由原地图数据控制。
- 订单页按示意图增加采购建议区，但库存没有数据源时明确显示“待计算”；能源环图按设备区与 AGV 区汇总。
- 物体定位后端未启动时只展示本地定位示意图，并提示识别结果需要后端，不生成模拟识别输出。
- 设计 PNG 中的数值、政策名称和算法框属于静态示例画面。实际业务操作区只展示项目已有数据和能力，不把示意图数值当作计算结果。
- 桌面端按 1672×941 基准等比缩放默认画面；窄屏使用折叠导航、流式卡片，地图及表格允许在组件内滚动。
- 交互和数据边界保持原有设计；物体定位页增加了不依赖后端的示意图预览。

## 与示意图仍有的差距

- 完全一致的是未经操作的 1672×941 默认画面。图中的人物、机械臂和车辆是静态像素；开始运行后，真实 SVG 地图与数据面板接管数据区。若要求图中人物或机械臂按实时数据逐帧运动，需要另做多状态精灵素材及动画逻辑。
- 设备监测仍没有传感器数据和判断规则；采购建议仍没有库存与安全库存；物体定位识别仍依赖任务 5 后端。这些区域不会使用设计图中的示意数值冒充真实结果。
- 八个页面的实际截图保存在 `前端页面设计/当前实现预览/新版-*.png`，可与同目录上级的八张示意图逐页对照。

## 验证

运行 `npm test`，再检查所有路由、视觉检测两个页签和 AGV、订单、能源的主要操作；检查 1366×768、1920×1080 和手机宽度下的溢出与可读性。

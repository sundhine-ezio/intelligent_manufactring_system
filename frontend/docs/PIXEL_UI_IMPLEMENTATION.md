# 像素风 Vue 界面实施说明

全部路由打开后直接显示 Vue 操作界面。已删除整张设计图展示、透明操作热区和点击后进入另一操作视图的机制。

## 实现

- 技术栈继续使用 Vue 3、Vue Router、Bootstrap、SVG、ECharts，无技术栈迁移。
- pixel-art.js 从设计图中通过 SVG viewBox 取局部插画：厂房、车辆、检测设备、模块插画、侧栏花盆货箱、顶栏窗景、监测主视觉及指南流水线。
- 页面标题、导航、按钮、输入、数值、表格、图表及地图车辆始终由 Vue 渲染。
- pixel-frame.svg 用于 border-image 九宫格边框，保留折角、多层描边及角部亮点。
- AGV 工位采用插画局部和真实 SVG 坐标；行驶车辆和路径仍由模拟逻辑更新。
- 设计图中的示意数值和识别结果没有被用作实际数据。

## 当前差距

装饰插画与设计图来自同一素材，但可操作区根据实际数据量重排，不承诺与整张静态位图逐像素相同。中文使用系统字体；人物和机械臂装饰为静态插画。设备监测仍需传感器数据，采购建议仍需库存，任务 5 识别仍依赖后端。

## 2026-11-09 细节调整

确认原先的裁图由固定容器高度与 slice 模式引起，分辨率只影响裁切程度。局部插画改为 meet 并加裁剪区域约束，防止等比留白时露出设计图中相邻的文字。首页主图使用素材固有比例，入口卡片加高；视觉检测、物体定位和监测主视觉增加展示空间。AGV 地图显示区使用 16:9，任务表下移并压缩行距。左右品牌、页签标题和页脚统一为“智能工厂”，品牌采用本地 Fusion Pixel 字体，标题与关键数字按青、绿、黄、紫分色。

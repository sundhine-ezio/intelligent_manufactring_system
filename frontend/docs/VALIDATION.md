# 第一版验证记录

验证日期：2026-11-04。

## 环境与结果

- 本机 Node.js v26.13.0；使用已安装的 Google Chrome 无界面运行浏览器检查。
- `npm.cmd test`：9 项全部通过。
- `npm.cmd run test:ui`：7 项全部通过。
- 检查 PC 窗口 1366×768 和 1920×1080，全部页面无横向溢出、无运行异常。
- 浏览器阻断非本地请求后仍可完成检查；应用没有请求远程 CDN。
- 对首页、AGV、视觉、订单、能源页面生成截图并检查，图片保存在 test-results。

## 主要覆盖

1. 地图所有工位组合的固定通道路线避开实体障碍，起终点与配置一致；修改停靠点后仍按工位编号引用。
2. 受阻停靠点、受阻路线、非整数通道明确拒绝。
3. AGV 新增、派单、选中路径、运行暂停、重置、退出页面停止计时、执行完成自动暂停。
4. 图片格式、10 MB 限制、损坏图像、有效上传预览；上传后没有伪造结果；物体坐标未标定时明确不可用。
5. 销量日期长度和六条序列对齐，周/月跨年汇总，切换筛选清除旧预测，反向日期报错。
6. 能耗手工可复算，允许零，拒绝缺失、负值、非数值与超出单日时长。
7. HTTP 接口失败显示错误，没有自动切换回模拟场景。
8. Vue 模板编译检查，防止代码排版破坏插值表达式。

## 验证边界

这些检查证明当前前端交互和已实现的简化逻辑可以运行，不证明工业算法准确率、最优调度、安全避碰、真实节能收益或真实后端兼容性。后端尚未实现，HTTP 失败场景使用请求阻断验证。尚未进行真实模型训练、完整数据集评价、移动端或其他浏览器兼容性验证。
